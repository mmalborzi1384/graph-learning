مهره بگذار، پوشش را ببین، و کمترین تعداد مهره را پیدا کن.

ابتدا مرحله‌ی ۱ را بزنید. اگر مجموعه احاطه‌گر بود، مرحله‌ی ۲ فعال می‌شود تا مینیمال و مینیمم بودن بررسی شود.

در حالت دو گروهی، نوبت بین «گروه A» و «گروه B» به‌صورت متناوب عوض می‌شود.

آماده
مهره: رنگ خودش پوشش‌داده‌شده: هاشور با رنگ مهره‌ی پوشاننده پوشش مشترک: دایره نیمه‌نیمه با همه‌ی رنگ‌ها پوشش‌داده‌نشده

آزمون حذف: آیا مجموعه مینیمال است؟

هر مهره را برای حذف انتخاب کنید (چند مهره هم می‌شود) و ببینید کدام رأس‌ها بی‌پوشش می‌شوند. اگر حذف هیچ مهره‌ای احاطه‌گری را خراب نکند، آن مهره زائد است و مجموعه مینیمال نیست.

    راهنمای سریع
    • روی رأس کلیک کنید تا مهره گذاشته یا برداشته شود. بعد از تأیید مرحله‌ی ۱، کلیک روی مهره‌ی بی‌نیاز آن را برای حذف انتخاب می‌کند؛ چند مهره را می‌توانید انتخاب و با «اعمال حذف» یکجا حذف کنید.
    • مهره، خود رأس و همسایگانش را پوشش می‌دهد.
    • مرحله‌ی ۱: احاطه‌گری را تأیید کنید. مرحله‌ی ۲: مینیمال و مینیمم بودن را تأیید کنید.
    • امتیاز: ۱۵ مینیمم (|D| = γ)، ۱۰ مینیمال ولی غیرمینیمم، ۵ احاطه‌گر ولی غیرمینیمال (یا بدون مرحله‌ی ۲)، ۰ احاطه‌گر نیست.

      ایستگاه ۲: کشف فرمول γ(Pn) و γ(Cn)

      مقادیر محاسبه‌شده را با ⌈n/۳⌉ مقایسه کنید.

      اثبات کران پایین: هر رأس حداکثر ۳ رأس را پوشش می‌دهد، پس ۳k ≥ n و k ≥ ⌈n/۳⌉. اثبات کران بالا: بلوک‌بندی سه‌تایی و انتخاب رأس‌های وسط.

      ایستگاه ۴: مینیمال در برابر مینیمم

      مجموعه‌ی احاطه‌گر مینیمال است اگر حذف هر مهره، احاطه‌گری را از بین ببرد. مجموعه‌ی مینیمم کوچک‌ترین مجموعه‌ی احاطه‌گر است (|D| = γ). هر مینیمم مینیمال است، ولی عکس آن همیشه درست نیست.

      مثال: در P۶ مجموعه‌ی {۲، ۴، ۶} مینیمال است (حذف هر عضو یک رأس را بی‌پوشش می‌گذارد)، ولی |D| = ۳ > γ(P۶) = ۲، پس مینیمم نیست.

      ایستگاه ۵: بازی رقابتی «چالش γ»

      1. دو گروه A و B ایجاد می‌شوند.
      2. گروه فعال گراف را روی صفحه‌ی بازی حل می‌کند.
      3. گروه مقابل مجموعه را تأیید یا رد می‌کند.
      4. امتیاز: ۱۵ / ۱۰ / ۵ / ۰ مطابق قوانین امتیازدهی دو مرحله‌ای.

      تعاریف و قضایا

      مجموعه‌ی احاطه‌گر: زیرمجموعه‌ی D ⊆ V احاطه‌گر است، هرگاه برای هر v ∈ V داشته باشیم: v ∈ D یا N(v) ∩ D ≠ ∅.

      مجموعه‌ی احاطه‌گر مینیمم: احاطه‌گری که کمترین تعداد عضو را دارد.

      عدد احاطه‌گری: γ(G) = min |D|، که کمینه روی همه‌ی مجموعه‌های احاطه‌گر D ⊆ V گرفته می‌شود.

      احاطه‌گر مینیمال و مینیمم

      مجموعه‌ی احاطه‌گر مینیمال: احاطه‌گر D است که هیچ زیرمجموعه‌ی سره‌ی آن احاطه‌گر نیست. به‌زبان ساده، حذف هر مهره‌ی آن یک رأس را بی‌پوشش می‌گذارد.

      مجموعه‌ی احاطه‌گر مینیمم: احاطه‌گری با |D| = γ(G)، یعنی کوچک‌ترین اندازه‌ی ممکن.

      • هر مجموعه‌ی مینیمم مینیمال است. (اگر زیرمجموعه‌ی سره‌ای احاطه‌گر باشد، γ کوچک‌تر از اندازه‌ی D می‌شد.)
      • عکس آن درست نیست: در P۶ مجموعه‌ی {۲، ۴، ۶} مینیمال است ولی مینیمم نیست، چون γ(P۶) = ۲.
      • هر مجموعه‌ی احاطه‌گر شامل یک مجموعه‌ی احاطه‌گر مینیمال است: مهره‌های زائد را یکی‌یکی حذف کنید تا دیگر حذف نشود.
      ویژگیمینیمالمینیمم
      شرطحذف هر عضو احاطه‌گری را خراب می‌کندکمترین اندازه است، |D| = γ(G)
      تعداد در یک گرافممکن است چند مجموعه با اندازه‌های مختلف باشدهمه‌ی مینیمم‌ها اندازه‌ی یکسان γ دارند
      بررسیبا حذف تک‌تک اعضابا مقایسه‌ی اندازه با γ

      فرمول‌ها

      • γ(Pn) = ⌈n/۳⌉ و γ(Cn) = ⌈n/۳⌉ (برای n ≥ ۳ در Cn)
      • γ(Kn) = ۱
      • γ(Km,n) = ۲ برای m,n ≥ ۲، و ۱ اگر m = ۱ یا n = ۱
      • γ(Sn) = ۱ (ستاره)، γ(Wn) = ۱ (چرخ)

      کران‌ها

      • کران پایین: γ(G) ≥ n / (Δ(G) + ۱)
      • قضیه‌ی اور: اگر G رأس منفرد نداشته باشد، γ(G) ≤ n/۲
      • افزودن یال: γ هرگز افزایش نمی‌یابد.

      نمادگذاری

      • Pn: مسیر با n رأس. Cn: دور با n رأس. Kn: گراف کامل با n رأس.
      • Sn: ستاره با n رأس (یک مرکز و n−۱ برگ).
      • Wn: چرخ؛ دور Cn به‌علاوه‌ی یک مرکز (n+۱ رأس).
      • N(v): همسایگان v.
      • N[v] = N(v) ∪ {v}.
      • Δ(G): بیشینه‌ی درجه.

      محاسبه‌ی خودکار γ برای گراف‌هایی با حداکثر ۱۰ رأس انجام می‌شود.
