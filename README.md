# چالش ⁦γ⁩ — بازی و آزمایشگاه احاطه‌گری

بازی و آزمایشگاه ریاضی برای آموزش **احاطه‌گری و عدد احاطه‌گری ⁦γ(G)⁩**.
مرجع: ریاضیات گسسته ۱۲، رشته‌ی ریاضی-فیزیک، فصل ۲ (مدل‌سازی با گراف)، درس ۲ (احاطه‌گری).

> برای توسعه‌دهندگان و هوش مصنوعی‌ها: **[DEVELOPER_GUIDE.md](DEVELOPER_GUIDE.md)** را بخوانید.

## اجرای برنامه

**روش ۱ (بدون نصب):** فایل `code/index.html` را در Chrome، Firefox یا Edge باز کنید.

**روش ۲ (سرور محلی):**
```bash
python3 -m http.server 8000 --directory code
# سپس: http://localhost:8000
```

## تست‌ها

### پیش‌نیاز (یک بار)
- Python 3.10+ و Node.js 18+
- وابستگی‌ها:
```bash
python3 -m pip install -r tools/requirements.txt
python3 -m playwright install --with-deps chromium
```

### اجرا
```bash
python3 tools/run_all.py          # همه‌ی تست‌ها (بیست و یک بخش، چند دقیقه)
python3 tools/run_all.py --fast   # فقط ریاضی و واحد و بررسی‌های ایستا (بدون مرورگر)
```
کد خروج `0` یعنی همه‌ی تست‌ها موفق‌اند. تست‌های تکی: `python3 tools/ui_bugs.py` و مانند آن.

اگر خطای `libnspr4.so` یا `Executable doesn't exist` دیدید، دستور `playwright install --with-deps chromium` را دوباره اجرا کنید.

## ویژگی‌ها

- **بازی «چالش ⁦γ⁩» (نسخه ۶.۴.۰):** انتخاب گراف، گذاشتن و برداشتن مهره، نمایش پوشش، بررسی و امتیاز دو مرحله‌ای ۰ / ۵ / ۱۰ / ۱۵ (احاطه‌گری، سپس مینیمال و مینیمم).
- **تمرین هدفمند (نسخه ۶.۴.۰):** اگر مجموعه احاطه‌گر بود ولی مینیمال نبود، دکمه‌ی «تمرین هدفمند» یک گراف کوچک‌تر با همان اشتباه می‌دهد؛ رأس زائد را بردارید و دوباره تأیید کنید.
- **چالش زمان‌دار (نسخه ۶.۴.۰):** ۵ گراف در ۳ دقیقه. امتیاز هر گراف از امتیاز دور و پاداش سرعت می‌آید. امتیاز در کارنامه ثبت نمی‌شود.
- **ویرایشگر کشیدنی گراف (نسخه ۶.۴.۰):** در «ساخت گراف سفارشی» رأس‌ها را بکشید؛ با «حالت یال» دو رأس را بزنید تا یال ساخته یا حذف شود.
- **ریل پیشرفت معرفی (نسخه ۶.۴.۰):** نوار طلایی عمودی در لبه‌ی راست صفحه‌ی معرفی نشان می‌دهد کجای معرفی هستید؛ هر نقطه یک بخش است و با کلیک می‌توانید به آن بخش بروید.
- **گزارش چاپی برای معلم (نسخه ۶.۴.۰):** دکمه‌ی «چاپ گزارش معلم» در تب کارنامه گروه‌ها، کارنامه و سابقه‌ی اخیر را برای چاپ یا PDF آماده می‌کند.
- **آزمون حذف (مینیمال بودن، نسخه ۶.۴.۰):** پس از تأیید مرحله‌ی ۱، هر مهره‌ی مجموعه را برای حذف انتخاب می‌کنید؛ می‌توانید چند مهره را همزمان انتخاب کنید. رأس‌های بی‌پوشش قرمز می‌شوند. با «اعمال حذف» مجموعه واقعاً به‌روز می‌شود و مرحله‌ی ۱ دوباره بررسی می‌شود؛ با «لغو انتخاب‌ها» مجموعه تغییر نمی‌کند. تا وقتی انتخاب حذف اعمال یا لغو نشده، مرحله‌ی ۱ و ۲ قفل‌اند. اگر حذف هیچ مهره‌ای احاطه‌گری را خراب نکند، آن مهره زائد است و مجموعه مینیمال نیست.
- **تب کارنامه (نسخه ۶.۴.۰):** جدول امتیاز گروه‌ها، سابقه‌ی دورها، خروجی CSV و کارنامه‌ی گراف‌ها در تب جدا «کارنامه» هستند. تب بازی خط امتیاز زنده را نشان می‌دهد.
- **بازگشت و تکرار:** دکمه‌ها و میان‌برهای Ctrl+Z و Ctrl+Y.
- **راهنمای سه‌سطحه:** رئوس پوشش‌نداده، یک رأس از مجموعه‌ی مینیمم، و سرانجام ⁦γ(G)⁩. راهنما امتیاز را تغییر نمی‌دهد.
- **صفحه‌ی معرفی (نسخه ۶.۴.۰):** `code/intro/index.html` یک صفحه‌ی روشن و پیمایشی است که تعریف مجموعه‌ی احاطه‌گر، مثال ⁦C₆⁩، کمینه بودن در ⁦P₇⁩، مینیمال در برابر مینیمم در ⁦P₆⁩ و قضیه‌ی ⁦γ(Pₙ) = γ(Cₙ) = ⌈n/۳⌉⁩ را با گراف‌های SVG نشان می‌دهد. بخش‌های مقایسه‌ای مثل کارت‌هایی هستند که با اسکرول یکی جای دیگری را می‌گیرد (محو متقاطع)؛ نوار طلایی بالای صفحه پیشرفت را نشان می‌دهد. از سربرگ بازی به آن می‌رسید. موتور حرکت `code/intro/vendor/scrollcraft.js` (MIT) است و نیاز به ساخت یا اینترنت ندارد.
- **گراف‌های آماده:** ۲۲ گراف شامل مسیر، دور، کامل، ستاره، دوبخشی، چرخ و گراف پترسن. ⁦γ⁩، مجموعه‌های مینیمم و مینیمال هر گراف محاسبه و نمایش داده می‌شوند.
- **ساخت گراف سفارشی:** از ۲ تا ۱۰ رأس، با ماتریس مجاورت. تعداد نامعتبر پیام خطا می‌دهد.
- **حالت دو گروهی:** نوبت متناوب؛ جدول امتیاز و سابقه‌ی دورها در تب «کارنامه».
- **کارنامه‌ها:** افزودن کارنامه‌ی جدید و صفر کردن کارنامه‌ی فعال، در تب «کارنامه».
- **ثبت و گراف بعدی:** بعد از ثبت، گراف تصادفی بعدی بارگذاری می‌شود.
- **خروجی CSV:** سابقه‌ی دورها برای Excel، در تب «کارنامه».
- **ظاهر:** پالت روشن (کرم، ذغالی، سبز تیره، طلایی) با فونت B Nazanin، ده رنگ متمایز برای مهره‌ها، و هاشور پوشش روی گراف با نسخه‌ی تیره‌ی همان رنگ‌ها. جزئیات در `docs/09_طرح_طراحی_ظاهری.md`.
- **آزمایشگاه:** پنج ایستگاه (محاسبه‌ی ⁦γ⁩ با همه‌ی مینیمم‌ها، کشف فرمول، کران‌ها و اثر یال، مینیمال در برابر مینیمم، بازی دو گروهی).
- **رنگ‌بندی پوشش (نسخه ۶.۴.۰):** هر مهره رنگ ثابت خودش را دارد. رأس‌های پوشش‌داده با هاشور همان رنگ پوشانده می‌شوند. اگر دو مهره یک رأس را پوشش دهند، دایره‌ی آن رأس بین دو رنگ تقسیم می‌شود. مهره‌ها هیچ رنگ دیگری نمی‌گیرند.
- **رسم بر اساس ⁦n⁩ و ⁦γ⁩ (نسخه ۶.۴.۰):** در بخش «رسم بر اساس ⁦n⁩ و ⁦γ⁩» تعداد رأس و عدد احاطه‌گری را وارد کنید تا گرافی با همان مشخصات رسم شود.
- **حالت بازی: امتیازی یا فقط تمرین (نسخه ۶.۴.۰):** کلید «امتیازی | فقط تمرین» در پنل بازی، جای چک‌باکس قبلی «تمرین مینیمال» نشسته است. در حالت تمرین امتیازی ثبت نمی‌شود، پیام‌ها بدون عدد امتیاز نشان داده می‌شوند، و تب کارنامه، کلید بازی دو گروهی، خط امتیاز زنده، قانون‌های امتیازی و ایستگاه ۵ با محو شدن پنهان می‌شوند. برگشت به امتیازی همه‌ی آن‌ها را دوباره نشان می‌دهد. در حالت تمرین، مینیمال بودن و مینیمم بودن مجموعه نشان داده می‌شود. این حالت امتیاز ندارد. چالش: مجموعه‌ای مینیمال بسازید که مینیمم نباشد.
- **مینیمال و مینیمم (نسخه ۶.۴.۰):** در تعاریف، ایستگاه ۴ و جعبه‌ی ⁦γ⁩، همه‌ی مجموعه‌های احاطه‌گر مینیمال یا مینیمم نمایش داده می‌شوند.

## نمادگذاری

| نماد | معنی |
|---|---|
| ⁦P_n، C_n، K_n⁩ | مسیر، دور، گراف کامل با ⁦n⁩ رأس |
| ⁦K_{m,n}⁩ | گراف دوبخشی کامل |
| ⁦S_n⁩ | ستاره با ⁦n⁩ رأس (یک مرکز و ⁦n−۱⁩ برگ) |
| ⁦W_n⁩ | چرخ: دور ⁦C_n⁩ به‌علاوه‌ی مرکز (⁦n+۱⁩ رأس) |
| ⁦N(v), N[v]⁩ | همسایگان؛ بسته‌ی همسایگی (با خود ⁦v⁩) |
| ⁦Δ(G)⁩ | بیشینه‌ی درجه |
| ⁦γ(G)⁩ | عدد احاطه‌گری |

## مجوز و منبع
آموزشی. منبع مفهومی: کتاب ریاضیات گسسته‌ی دوازدهم ریاضی-فیزیک (ایران).

- **پس‌زمینه‌ی متحرک (هر تب یک انیمیشن):** هر تب صحنه‌ی احاطه‌گری خودش را دارد: بازی ← گراف پترسن (مجموعه‌ی کمینه ‎{۴، ۷، ۸}‎، γ = ۳)، کارنامه ← دور C₆ (‎{۱، ۴}‎، γ = ۲)، آزمایشگاه ← ستاره‌ی S₄ (‎{۱}‎، γ = ۱)، تعاریف ← مسیر P₇ (‎{۲، ۵، ۶}‎، γ = ۳). انیمیشن در کل طول همان تب، با اسکرول پخش می‌شود: ۰ تا ۸ ثانیه رسم و ۸ تا ۱۰ ثانیه محو؛ با بالا آمدن اسکرول برمی‌گردد. روی بوم فقط گراف است. پنل‌ها نیمه‌شفاف‌اند تا صحنه‌ی کم‌رنگ دیده شود. با کاهش حرکت، فریم ۸ ثانیه‌ی صحنه‌ی فعال نشان داده می‌شود. موتور: `code/js/dom-scene.js`؛ داده‌ی صحنه‌ها: `code/js/scenes.js`؛ استایل: `code/css/petersen-bg.css`. نسخه‌ی مستقل C₆ و S₄ در `code/animations/` هم هست.
- **حالت تاریک (کلید، نسخه ۶.۴.۰):** کلید «حالت تاریک» در سربرگ بازی و صفحه‌ی معرفی؛ با تغییر حالت، دایره‌ای از محل کلید گسترده می‌شود. پیش‌فرض روشن است و انتخاب در مرورگر ذخیره می‌شود (`js/theme.js`). مهره‌ها و هاشورها در هر دو حالت یک‌سان‌اند.

## انتشار آنلاین (GitHub Pages)

۱. یک مخزن جدید در GitHub بسازید و محتوای این پوشه (`chalesh-gamma`) را در ریشه‌ی آن بگذارید، شامل پوشه‌ی `.github`.
۲. در GitHub به Settings → Pages بروید و در بخش Source گزینه‌ی **GitHub Actions** را انتخاب کنید.
۳. کد را push کنید (`main` یا `master`). فایل `.github/workflows/pages.yml` فقط پوشه‌ی `code/` را منتشر می‌کند.
۴. پس از اجرای موفق Actions، نشانی سایت به شکل `https://<نام‌کاربری>.github.io/<نام‌مخزن>/` است و در همان صفحه‌ی Actions نمایش داده می‌شود.

تمام لینک‌های سایت نسبی هستند، پس با نشانی زیرپوشه هم کار می‌کنند. فایل‌های `tools/` و `docs/` منتشر نمی‌شوند.
